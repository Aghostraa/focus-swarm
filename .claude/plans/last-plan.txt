 Plan: Cortex — Decentralized Agent Framework (OpenClaw-Inspired, 0G-Native)              
                                                                                          
 Context                                                                                  
                                     
 The user wants to position cortex not as "3 specific agents" but as a framework for
 building persistent, self-evolving agents — inspired by OpenClaw but fully decentralized
  on 0G + AXL + ENS. Three protocol expert agents (zerog, axl, ens) serve as the
 canonical example agents.

 Key design decisions from user:
 - Implicit message-passing over explicit tool call schemas (POST /ask {message} not MCP
 JSON-RPC)
 - Self-evolution is a primary goal — agents consolidate memory and re-upload brain after
  interactions
 - On-chain brain update — ENS agent.resume always points to latest rootHash after
 agent.save()
 - iNFT mint — full on-chain identity via ERC-7857 + ENS subname
 - Both AXL + HTTP interfaces

 What Already Works (don't rebuild)

 The hard infrastructure is done:
 - packages/kit/src/Agent.ts — Agent.create() uploads brain to 0G + registers ENS;
 agent.save() re-uploads + updates ENS; agent.listen() / agent.send() for AXL;
 agent.ask() for verifiedReason
 - packages/kit/src/skills/selector.ts — selectSkillsForTask(skills, message)
 auto-selects skills from natural language
 - packages/kit/src/memory/consolidate.ts — consolidateMemory(brain, events) via 0G
 Compute
 - packages/protocol-twins/src/runtime.ts — AXL pump loop, query/answer SwarmMsg handling
 - packages/protocol-twins/src/spawn.ts — multi-twin spawner reading JSON configs
 - infra/axl/spawn.sh — boots N AXL nodes
 - .claude/skills/*/SKILL.md — 5 skill packs (stubs, need content)
 - Apply-twin as complete reference implementation

 import { loadSkillDirectory, selectSkillsForTask, buildSkillPrompt } from '@cortex/kit';

 // On startup: load all skill packs from .claude/skills/
 const skillDir = resolve(process.env.SKILL_DIR ?? '.claude/skills');
 const allSkills = await loadSkillDirectory(skillDir);
 const agentSkills = allSkills.filter(s => config.skills?.includes(s.name));

 // In onMessage handler:
 const selected = selectSkillsForTask(agentSkills, msg.question);
 const enrichedPrompt = buildSkillPrompt(selected, msg.question);
 const messages = [
   { role: 'system', content: config.mission },
   ...(msg.context ? [{ role: 'user', content: `Context: ${msg.context}` }] : []),
   { role: 'user', content: enrichedPrompt },
 ];
 const result = await verifiedReason(messages);

     Framework Positioning (for README/demo)

     Cortex = OpenClaw-inspired, fully decentralized:
     - Brain: encrypted/plaintext on 0G Storage, content-addressed
     - Identity: ENS subname with agent.resume → latest brain rootHash
     - Ownership: ERC-7857 iNFT on Galileo
     - Messaging: AXL P2P (Yggdrasil mesh, no central broker)
     - Inference: 0G Compute (Qwen 2.5) with TeeML seal — every response provable
     - Evolution: episodic log → consolidateMemory → re-upload → ENS update, automatically
     - Discovery: GET /personas on ENS gateway, filter by protocol/market
     - Integration: POST /ask on any agent — no schema, no SDK required
