Plan: Persona Awakening, Marketplace Discovery, Configurable Moderator, Ground Truth       
                                                                                            
 Context                                                                                    

 The core focus-swarm pipeline (mint → AXL cohort → moderator → synthesizer → report) is
 fully implemented. The gap is:
 1. Personas are thrown away after each session — no reuse
 2. Researcher has no way to find or preview interesting past personas
 3. Moderator is generic — no way to configure research goals or style
 4. Persona brains are generated cold with no real behavioral grounding

 The user wants: personas that "apply" to participate in new research (agent autonomy
 demo), a library to browse and accept them, configurable moderator, and real personality
 data as ground truth.

 Hackathon tracks served: 0G Autonomous Agents (awakening = verified inference per
 persona), Gensyn AXL (awakening pings via AXL or REST), ENS (discovery catalog = ENS text
 records).

 ---
 What NOT to build (out of scope)

 - Token trading / revenue sharing marketplace contract
 - EIP-3668 phase 2 (CCIP signing)
 - Ratings / voting system
 - Persistent memory growth across sessions (complex, deferred)

 Feature 2 — Persona Awakening

 Concept: Researcher creates a proposal (market + brief) → system fetches all catalog
 personas → for each one matching market, loads brain from 0G Storage → calls 0G Compute to
  generate a 1-2 sentence "expression of interest" (verified) → researcher sees these
 mini-responses and picks which to include.

 This is the agent-autonomy story: personas deciding whether they want to participate.

 New function: packages/smith/src/index.ts — export awakenPersonas(market, brief, limit=6)

 async function awakenPersonas(market: string, brief: string, limit = 6):
 Promise<AwakenResult[]>

 Flow per persona:
 1. GET /personas?market=<market> from ENS gateway
 2. For each (up to limit): parse agent.resume → extract rootHash →
 downloadDecrypted(rootHash, key)
   - Key problem: AES key is stored in infra/axl/keys/persona-<tokenId>.aes (written by
 smith at mint time). For hackathon: load from local file by tokenId.
 3. Call chat() with persona's system prompt + the research brief → generate "application"
 (1-2 sentences in persona voice)
 4. Return: { ensName, tokenId, archetype, targetMarket, applicationText, verified,
 rootHash, keyPath }

 New CLI command packages/smith/src/cli.ts:
 pnpm -F smith awaken -- --market="urban renters" --brief="save cart feature" --limit=4

 New API endpoint packages/ui/src/app/api/awaken/route.ts:
 POST /api/awaken { market, brief, limit }
 → returns AwakenResult[]

 Feature 5 — Real Personality Ground Truth

 New file: packages/smith/src/ground-truth.ts

 Two-layer approach (most efficient for hackathon):

 Layer 1 — Big 5 archetype map (static, zero API calls)
 const BIG5_BY_ARCHETYPE: Record<string, Big5Scores> = {
   'gen-z-berlin-renter': { openness: 0.8, conscientiousness: 0.4, extraversion: 0.6,
 agreeableness: 0.5, neuroticism: 0.6 },
   // ... common archetypes
 }
 Sourced from academic LIWC / Big 5 literature on demographic groups. Hardcoded lookup with
  fuzzy match on archetype slug.

 Layer 2 — Reddit voice samples (live fetch, cached)
 async function fetchRedditVoice(archetype: string): Promise<string[]>
 - Maps archetype slug → list of subreddits (e.g. gen-z-berlin-renter → r/berlin, r/GenZ,
 r/Apartmenttherapy)
 - Hits Reddit JSON API (https://www.reddit.com/r/{sub}/hot.json?limit=10) — no auth needed
  for public hot posts
 - Extracts post titles + top comment text
 - Returns 8-12 short excerpts as voice samples
 - Caches to infra/deploy/voice-cache/{archetype}.json to avoid re-fetching

 Wire into generatePersona() in packages/smith/src/index.ts:
 - Before calling chat(), call fetchGroundTruth(archetype) → { big5, voiceSamples }
 - Inject into system prompt as additional context:
 Personality anchors (Big 5): openness=0.8, conscientiousness=0.4 ...
 Voice samples from their communities:
 - "Just moved to Neukölln, the vibe is different but I love it"
 - "Anyone else using Splitwise for everything?"

 Decisions (confirmed)

 1. AES key storage: Local files (infra/axl/keys/persona-{tokenId}.aes) — fine for
 hackathon.
 2. Awakening scope: Match by agent.target_market — only ping personas whose market
 overlaps the proposal.
 3. Ground truth: Both layers — Big 5 anchors (static, academic) + Reddit voice samples
 (live fetch, cached).
