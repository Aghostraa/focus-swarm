Plan: Persistent Persona Memory, Skill Accumulation & Role-Aware Sessions
                                     
 Context

 The previous plan (awakening, catalog, ground truth, configurable moderator) is complete.
 Personas now have rich WD-grounded personalities and can apply to research proposals. But
 they still die after each session — their brain blob is static, their KV state
 (mood/turnsSpoken) resets, and every session starts cold.

 The infrastructure for persistence is already wired: kvSet/kvGet/logAppend on 0G KV,
 encrypted brain blobs on 0G Storage, ENS agent.resume pointing to the current brain.
 What's missing is the feedback loop:

 session ends → skill assessment (verified 0G Compute) → brain re-encrypted with updated
 skills → new rootHash → ENS updated → next session starts smarter

 This makes persona growth provable on-chain — the ENS record's agent.resume hash changes
 after every session, and the 0G Storage blob at that hash contains verifiably upgraded
 skills.

 Longer-term direction (explicitly out of scope now): personas with roles acting as a code
 review / dev team.

 ---
 What NOT to build (this plan)

 - Tool access per role (file reading, code execution, PR generation)
 - Skill decay / forgetting over time
 - Cross-persona relationship memory
 - Real-time skill display during sessions
 - Full dev-team / code-writing mode

 Phase 4 — Post-Session Persona Evolution

 File: packages/smith/src/index.ts

 Add evolvePersona(params): Promise<EvolveResult | null>:

 interface EvolveParams {
   tokenId: number;
   ensName: string;
   currentSpec: PersonaSpec;
   currentKey: Buffer;
   myUtterances: string[];      // this persona's lines from transcript
   reportThemes: string[];
   reportOpportunities: string[];
   productBrief: string;
 }

 interface EvolveResult {
   newRootHash: string;
   updatedSkills: PersonaSkills;
 }

 Flow:
 1. Verified skill assessment via chat():
   - System prompt: skill evaluator role, JSON output spec:
 { sessionSummary: string, domainDeltas: Record<string,number>, uxLiteracyDelta: number,
 technicalDepthDelta: number, communicationMaturityDelta: number }
   - User prompt: persona archetype + role + utterances (≤10) + report themes
   - All deltas clamped to [-0.1, +0.1]
   - If !r.verified → return null (skip evolution, log warning)
 2. Merge skills into updated PersonaSpec:
 const updated: PersonaSkills = {
   sessionCount: current.sessionCount + 1,
   role: current.role,
   domainKnowledge: mergeDeltas(current.domainKnowledge, delta.domainDeltas),
   uxLiteracy: clamp01(current.uxLiteracy + delta.uxLiteracyDelta),
   technicalDepth: clamp01(current.technicalDepth + delta.technicalDepthDelta),
   communicationMaturity: clamp01(current.communicationMaturity +
 delta.communicationMaturityDelta),
   sessionSummaries: [...current.sessionSummaries.slice(-4), delta.sessionSummary],
 };
 3. Re-encrypt + upload updated brain blob → newRootHash
 4. Update ENS agent.resume = 0g://${newRootHash} via registerEns() POST to gateway
 5. Update KV persona:${tokenId}:skills for fast lookup at next spawn (optional fast path —
  runtime already loads from blob)
 6. Return { newRootHash, updatedSkills }

 Add helpers:
 - clamp01(v: number): number — clamp to [0, 1]
 - mergeDeltas(base: Record<string,number>, deltas: Record<string,number>):
 Record<string,number> — apply deltas, clamp results
