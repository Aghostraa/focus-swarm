# Professional Profile Context

Copy this file to `profile-context.md` and customize with your background.

## Summary

One paragraph describing who you are professionally. Used in every letter.

**Template:**
```
[Your Name] | [Your Title/Domain]
- [X years] building [domain], with focus on [specialization]
- Skills: [skill 1], [skill 2], [skill 3]
- Target roles: [role 1], [role 2] at [company types]
- Culture: [values], [working style]
```

**Example:**
```
John Doe | Full-stack agent architect
- 10+ years building autonomous systems, 0G infrastructure, P2P protocols
- Skills: Go, TypeScript, cryptography, systems design
- Target: Senior IC roles in AI infrastructure / blockchain core
- Culture: Data-driven, async-first, long-term ownership
```

## Experience

List 3–5 key roles/projects with emphasis on *shipped results*, not titles.

Format:
```
### [Company/Project Name] | [Duration or status]

- [What you built or shipped]
  - Metric/outcome: [numbers or impact]
- [Problem you solved]
  - How it mattered: [business/technical impact]
```

**Example:**
```
### MEV Labeling Agent | 2023–2024
- Built encrypted inference agent for protocol analysis
  - Reduced reliance on centralized oracle by 40%
- Designed 0G Storage + Compute integration for persistent state
  - Enabled trustless agent reuse across protocols

### Payment Processing Platform | 2019–2022
- Led architecture refactor from monolith to microservices
  - Cut latency by 60%, unlocked 3x throughput
- Built real-time settlement system handling $2B/month
  - Shipped v1 in 6 weeks with 2-person team
```

## Skills

Technical + domain skills relevant to your target roles.

**Example:**
```
### Systems & Infrastructure
- Go, TypeScript, Rust
- Distributed systems, P2P protocols, cryptography
- 0G Storage/Compute SDK, EVM smart contracts

### Product & Soft Skills
- Product thinking: rapid discovery loops, user/metric-driven
- Technical writing & public communication
- Team leadership (cross-functional, async)
```

## Target Roles

List 2–3 role types you're actively pursuing.

**Example:**
```
- Senior Infrastructure Engineer (agent + autonomous systems)
- Engineering Manager (small teams solving hard problems)
- Founder/Co-founder (AI agents, distributed systems)
```

## Key Gaps

Be honest about what you're *not* strong in. Frames how letters address skepticism.

**Example:**
```
- ML/AI (limited hands-on experience beyond LLM APIs)
- DevOps/SRE (no operational background)
- Sales/GTM (not a strength, but learning from partnerships)
```

## Culture & Working Style

What environment lets you do your best work?

**Example:**
```
- Async-first, low-meeting culture
- Long-term ownership (ship quarterly, not daily)
- Data-driven decisions (metrics, not opinions)
- Direct communication, low politics
- Room for deep technical work (not context-switching)
```

## Proof Points

Specific, quantified achievements letters can reference.

**Example:**
```
- Shipped production system in 6 weeks with 2 people (vs. 6-month estimate)
- Reduced infrastructure costs by 40% through architectural changes
- Diagnosed subtle protocol vulnerability before mainnet (prevented $10M+ loss)
- Built team from 0 → 5 engineers, ship cadence improved 3x
```

## How to Update

- **New job:** Add to Experience, update Target Roles if changed
- **New skill:** Add to Skills
- **Positioning shift:** Update Summary + Culture
- **Realized gap:** Update Key Gaps

The twin loads this on every draft. Keep it fresh = better letters.
