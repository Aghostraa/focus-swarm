# AXL Mesh

Yggdrasil-based peer-to-peer overlay mesh for agent communication. Each agent process runs next to a dedicated AXL node. Messages are routed through the encrypted mesh by public key.

---

## Port scheme

Per node (i = slot index 0…N):

| Purpose | Port formula | Node 0 | Node 1 | Node 2 |
|---------|-------------|--------|--------|--------|
| TLS listener (Yggdrasil peer) | `9101 + i×10` | 9101 | 9111 | 9121 |
| HTTP API bridge | `9002 + i×10` | 9002 | 9012 | 9022 |
| MCP router | `9003 + i×10` | 9003 | 9013 | 9023 |
| A2A server | `9004 + i×10` | 9004 | 9014 | 9024 |

Node 0 is the bootstrap peer. All other nodes set `"Peers": ["tls://127.0.0.1:9101"]`.

## spawn.sh

```bash
bash infra/axl/spawn.sh <N>
```

Spawns N+1 nodes (N persona nodes + 1 moderator at slot 0). Total nodes = N+1.

```bash
bash infra/axl/spawn.sh 3   # 4 nodes: slots 0–3
```

What it does:
1. Generates ed25519 key if missing: `openssl genpkey -algorithm ed25519 -out infra/axl/keys/node-<i>.pem`
2. Writes per-node config: `infra/axl/configs/node-<i>.local.json`
3. Starts each node as a background process, logging to `infra/axl/logs/node-<i>.log`
4. Queries each node's pubkey via `GET :9002/topology` (retries 5× with 1s backoff)
5. Writes `infra/axl/peers.local.json` with all pubkeys + ports

### Verify mesh

```bash
curl http://localhost:9002/topology
# Should show 3+ peers (nodes 1–3 visible from node 0)
```

## AXL binary

The binary must be at `infra/axl/bin/node` (macOS/Linux) or set `AXL_BIN` env var.

**Build from source (requires Go 1.21+):**

```bash
cd ../0g-doc/axl
make build
cp ./node /path/to/focus-swarm/infra/axl/bin/node
chmod +x infra/axl/bin/node
```

**Linux production:** `infra/axl/bin/node-linux` (pre-built for Fly deployment).

## Node config format

`infra/axl/configs/node-<i>.local.json`:

```json
{
  "PrivateKeyPath": "infra/axl/keys/node-0.pem",
  "Listen": ["tls://127.0.0.1:9101"],
  "Peers": [],
  "api_port": 9002,
  "router_addr": "http://127.0.0.1",
  "router_port": 9003,
  "a2a_addr": "http://127.0.0.1",
  "a2a_port": 9004,
  "bridge_addr": "127.0.0.1"
}
```

Node i > 0 sets `"Peers": ["tls://127.0.0.1:9101"]` to bootstrap from node 0.

## Keys

`infra/axl/keys/node-<i>.pem` — ed25519 private key. Never commit.

`infra/axl/keys/persona-<slug>.pem` — generated by `@cortex/smith` for persona nodes.

`infra/axl/keys/persona-<tokenId>.aes` — AES-256 brain encryption key. Never commit.

## peers.local.json

Written by `spawn.sh` after startup:

```json
[
  { "slot": 0, "pubkey": "0x3f2a...", "apiPort": 9002, "mcpPort": 9003, "a2aPort": 9004 },
  { "slot": 1, "pubkey": "0x7b8c...", "apiPort": 9012, "mcpPort": 9013, "a2aPort": 9014 },
  ...
]
```

Read by orchestrator/moderator to build the peer map.

## HTTP API bridge endpoints

The `AxlClient` in `@cortex/core` speaks only to the HTTP bridge.

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/topology` | GET | Node info + connected peer list |
| `/send` | POST | Send message to a peer by pubkey |
| `/recv` | GET | Long-poll for one message (204 = empty) |

`/send` body:
```json
{ "peerId": "0x3f2a...", "payload": { "type": "peer_query", ... } }
```

Header: `X-Destination-Peer-Id: <pubkey>` (used by some bridge implementations).

## MCP router

The AXL MCP router (`router_port`) exposes registered skill packs as JSON-RPC 2.0 tools. Claude Desktop connects here. Protocol twins register skills at boot via `registerSkillAsMcpTool()`.

MCP JSON-RPC endpoint: `POST http://127.0.0.1:9003/`

Tool call format:
```json
{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "params": { "name": "zerog-recipes", "arguments": { ... } },
  "id": 1
}
```

## Troubleshooting

**"AXL binary missing"**
```bash
ls infra/axl/bin/node    # check it exists
chmod +x infra/axl/bin/node
```

**Topology shows < N peers**  
Wait 5–10 seconds after spawn. Yggdrasil mesh takes a moment to peer.

**Port conflict**
```bash
lsof -ti:9101 | xargs kill -9   # kill node occupying TLS port
```

**Key regeneration**
```bash
rm infra/axl/keys/node-<i>.pem
bash infra/axl/spawn.sh 3   # regenerates on next spawn
```
